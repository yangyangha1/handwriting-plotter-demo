v0.8 个人字体自动完善与少样本泛化实现说明

一、目标
1. 固定通用汉字知识负责标准笔顺、IDS结构、组件归属。
2. 每个用户/profile拥有独立的个人参数和真实字迹库。
3. 用户每次只需继续导入正常手写文本图片；有效样本自动加入个人样本库并触发模型更新。
4. 新模型必须经过“按汉字隔离”的留出验证；变差自动回滚。
5. 主动学习根据当前缺口选择下一批最有信息量的汉字，减少无效重复输入。

二、两个轻量网络
A. Writer Structure NN
输入：笔画数、组件数、IDS根结构、标准字bbox/宽高等。
输出：整体X/Y尺度变化、X/Y重心偏移。
用途：学习某个人左右结构、上下结构、整体压缩/展开和重心习惯。

B. Writer Stroke NN
输入：标准轨迹(x,y,t)、切向、曲率、笔画序号、总笔画数、局部位置、component、IDS结构。
输出：逐轨迹点Δx/Δy。
用途：补偿组件/位置/结构/邻接统计模型仍无法解释的个人局部笔画变形。

生成顺序：
MMH标准轨迹
→ 全局统计风格
→ 精确偏旁逐笔风格
→ 组件位置/结构/邻接模型
→ Structure NN
→ Stroke NN
→ 受个人方差约束的自然扰动
→ SVG/JSON/G-code

三、自动持续学习
每一批有效图片：
图片→OCR→错误直接排除→Facsimile真实轨迹→写入facsimile_library
→ 汇总历史全部样本
→ 按字符划分train/validation
→ 训练候选模型
→ 留出字验证
→ 若验证改善：建立新版本并激活
→ 若验证退化：拒绝候选并恢复上一版本

注意：按“字符”隔离，而不是随机拆笔画。比如训练集中有“你”的一个版本，验证集中绝不能再出现另一个“你”，否则会高估泛化能力。

四、模型版本
style/continual_state.json：当前激活版本、最佳验证误差、历史记录。
style/versions/vXXXX/：每个通过验收的模型快照。

新候选综合验证误差由 Structure NN 和 Stroke NN 的留出误差加权组成。当前默认结构误差权重0.35、笔画轨迹误差0.65。

五、主动学习
style/active_learning_plan.json 保存：
- 当前需要继续补写的字符；
- 每个候选字的评分；
- 能补哪些缺失/不足偏旁；
- 是否覆盖当前验证薄弱结构。

用户仍按正常连续书写方式写这些字符/文本，不使用方格输入。

六、READY原则
固定样本数量只作为最低安全门槛，不再代表最终完成。
至少还必须能够形成独立验证集，并且候选个人模型通过验证验收。
如果样本不足：NEED_MORE_SAMPLES，软件继续给出主动学习建议。
如果新增样本导致候选模型变差：自动回滚，不污染已经稳定的个人模型。

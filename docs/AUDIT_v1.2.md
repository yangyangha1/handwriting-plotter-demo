# v1.2 代码复核与功能验收

本记录基于 v0.9 的完整实测结果，并结合 `MERGE_NOTES_v1.2.md` 完成版本整合。1.2 新增项目自带虚拟环境启动器、首次 Python 检测、项目内依赖缓存和数据目录读取；保留基于 0.8 前端骨架的逐项环境操作、步骤式显示和无效图片占位处理；未宣称已完成新的硬件闭环验证。

## 结论

交付的是完成工程补齐并经实际测试的迭代版，不是“完美复刻任意草书、从少数样本生成完整个人字体”的完成版。这个验收目标仍未通过。

## 本次修复

- 主GUI从Qt依赖切换为本地Web，保留桌面旧源码为可选兼容项。
- 增加标准库环境检查启动器，科学计算库缺失不阻止环境页启动。
- 增加独立轮廓路线，原稿视觉复刻不再因笔顺歧义被整个丢弃。
- 增加TrueType轮廓导出，保留孔洞并验证字符映射。
- 新增中心骨架每边一次遍历，闭环不遗漏；明确不宣称真实落笔顺序。
- OCR的NumPy数组不能用`or`判断：改为显式None判断。
- 禁用Paddle页面方向变换/去畸变，避免变化后的坐标被直接用于原图切块；文本行方向模块保留。
- 修复连通域接口参数位置，显式传`connectivity=8`。
- 新模型没有验证分数时，不能覆盖已经存在的有效版本；缺验证时readiness不再为READY。
- 严格生成缺readiness对象时拒绝，避免缺状态绕过门控。
- 最近先验点距离从巨大像素×采样点矩阵改为cKDTree，降低单字拟合内存。
- 字库导出逐字写JSONL，避免完整字库几百万坐标同时堆积为Python列表；轮廓简化改为OpenCV实现。
- 缺字显式拒绝、实验输出标注来源；未使用操作系统字体静默补字。
- 本地请求令牌、文件目录边界、上传体积限制、串行后台任务与错误显示。
- 修复移动端布局溢出；整理类型、未使用变量与格式问题。

## 真实数据测试

公开样稿：《快雪时晴帖（局部）》500×779像素缩略图。
来源：https://commons.wikimedia.org/wiki/File:快雪時晴帖(局部).jpg
下载源：https://upload.wikimedia.org/wikipedia/commons/thumb/2/2f/%E5%BF%AB%E9%9B%AA%E6%99%82%E6%99%B4%E5%B8%96%28%E5%B1%80%E9%83%A8%29.jpg/500px-%E5%BF%AB%E9%9B%AA%E6%99%82%E6%99%B4%E5%B8%96%28%E5%B1%80%E9%83%A8%29.jpg
原尺寸地址403，缩略图下载成功。不是人工渲染文字伪装的手稿。

1. 自动阈值留下较多纸纹，比较0/65/85/105后采用85；效果图在evidence。
2. OCR输出25个候选。`未累為結力不次`段有漏字后整体错位，排除。复核保留`快雪時晴佳想山陰張侯`。
3. 原稿轮廓与阈值后墨迹IoU约99.8%（轮廓简化迭代前约99.4%）。指标不包括照片颜色、纸纹剔除正确性或真实笔顺，不是“99.8%字体学习完成度”。
4. 输入`快雪時晴佳想\n山陰張侯 天地玄黃`，导出14字TTF，10字为实样、4字为未见字实验估计；在Chromium中实际加载TTF，与SVG对照。
5. 留出`雪晴陰張`，仅用余下6字统计生成，归一化墨迹IoU分别约0.22、0.23、0.38、0.21，均值约0.26。该指标不等于主观风格分，但足以否定当前完美复刻结论。
6. 原层级拟合流程只接受10个候选中的3个，状态NEED_MORE_SAMPLES，不能宣称神经模型训练已完成。
7. 批量导出9574字，约97秒完成（本环境单次实测，不是设备性能保证）。TTF与逐字路径包均实际生成。

## 尚未解决的模型问题

当前小网络没有通用书法预训练基础。把少量样本几何残差叠加到MMH楷书，无法推出草书的省笔、合笔和结构替换。静态图片也不能唯一确定时间笔顺。增加Web界面或TTF导出不改变这一点。

DeepCalliFont的公开实现使用图像/序列双分支与预训练，并非在原微型网络外加一层GUI：
https://github.com/lsflyt-pku/DeepCalliFont
https://arxiv.org/abs/2312.10314
本次仅查阅其公开说明，没有下载并训练该模型，更没有用论文结果替代本项目实测。

后续要满足用户目标，必须接入并验证具有草书数据的生成模型，建立多个书写者/未见字符的独立测试集；时序目标还需在线笔迹数据。未达到这些条件，不能继续将少量样本覆盖率视为字体完成度。

## 验证范围

测试日志、静态检查、环境依赖版本、浏览器截图与指标JSON随包提供。通过的单元测试不能证明所有自然手稿都有效。Windows/macOS安装和写字机物理动作未在本环境实测。持续学习的历史分数跨不同留出集合仍不能直接当作严格同分布比较，需固定评估集后再用于生产模型晋级。
